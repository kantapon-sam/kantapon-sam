## Featured projects

### [TrueOps Toolkit](https://github.com/kantapon-sam/TrueOpsToolkit)

A unified Windows desktop launcher for four PROMS workflow tools.

- Brings approval, reference-based approval, site deletion, and TK07 review into one interface with shared settings.
- Checks page readiness and confirms approval results against a fresh pending-request search.
- Includes application updates with SHA-256 verification, rollback support, and preservation of user settings and files.

**Built with:** Java, Swing, Selenium, PowerShell  
[Explore the code](https://github.com/kantapon-sam/TrueOpsToolkit) · [Releases](https://github.com/kantapon-sam/TrueOpsToolkit/releases)

### [BotGetLog Multi](https://github.com/kantapon-sam/BotGetLog_Multi)

A Java toolkit for network log collection and operational reporting.

- Collects device output through SSH and Telnet workflows, with tooling for multiple network vendors.
- Includes LLDP, optical-link, ARP, PTP, MPLS, and SID reporting tools.
- Provides regression checks for transcript parsing, collection behavior, and report generation.

**Built with:** Java, SSH/Telnet, Apache POI  
[Explore the code](https://github.com/kantapon-sam/BotGetLog_Multi) · [Releases](https://github.com/kantapon-sam/BotGetLog_Multi/releases)

### [AutoRequestTUAR](https://github.com/kantapon-sam/AutoRequestTUAR)

A desktop application for submitting TUAR requests from an Excel workbook.

- Refreshes available form choices from the portal and validates enabled request rows before submission.
- Handles dynamic form updates and reports skipped rows with their reasons.
- Limits automatic retries to the form-filling stage, avoiding automatic resubmission after SUBMIT is clicked.

**Built with:** Java, Swing, Selenium, Apache POI  
[Explore the code](https://github.com/kantapon-sam/AutoRequestTUAR) · [Releases](https://github.com/kantapon-sam/AutoRequestTUAR/releases)

### [CreateWorkOrderProms](https://github.com/kantapon-sam/CreateWorkOrderProms)

A Java application for creating PROMs work orders from structured CSV input.

- Uses site, project, and date fields to drive a repeatable work-order workflow.
- Provides a dry-run mode and versioned release packages.
- Includes an update flow with download and installation progress.

**Built with:** Java, browser automation, CSV, Apache Ant, NetBeans  
[Explore the code](https://github.com/kantapon-sam/CreateWorkOrderProms) · [Releases](https://github.com/kantapon-sam/CreateWorkOrderProms/releases)
